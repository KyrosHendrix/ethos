# ethos identity

Approved direction: **A, Margin**, in **Forest**.

The mark separates a vertical page margin from three text lines to form an E. The shorter middle line preserves recognition at toolbar sizes.

- Forest: `#284d3c`
- Paper: `#faf9f4`
- Wordmark: lowercase `ethos`, using the app's system sans serif.

`public/ethos.svg` is the source for the in-app mark and favicon. Run `python scripts/create-icon.py` to regenerate the PNG and Windows icon assets from this vector. This command only generates artwork; it does not build or package the app.
